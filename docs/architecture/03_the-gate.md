# Offline export and live browser gates

The shared Python classifier in `data-pipeline/engine/core/gate.py` records dependency, runtime and artifact-size eligibility. These resource checks do not prove that a browser implementation exists.

ChronoScope's export stage always labels its offline roster **precompute** and records the families' runtime dependencies. Fast native or package forecasts remain offline results. Historical admitted manifests retain their original classifier fields and source identity; those fields are not evidence that the current browser executes that historical Python roster.

The actual browser methods are five TypeScript rules and a self-hosted ONNX graph. Their numerical checks execute those implementations in Chromium, and the installed shell separately checks rendered routes, interactions, accessibility and motion. See [live computation](04_live-computation.md).
