# ChronoScope 0.24.000 release

All four remaining research extensions are implemented, validated and deployed:
large-corpus forecastability with corrected confirmation; exact Matrix Profile/FLUSS and
original-axis annotations; multiscale entropy, binary Lempel-Ziv and reversal diagnostics;
and isolated seeded nonlinear fits with twice-reproduced case analysis.

experiment retains the negative ContextMemory comparison. No configuration was tuned on confirmation.
