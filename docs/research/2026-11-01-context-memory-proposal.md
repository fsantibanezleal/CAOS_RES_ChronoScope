# ContextMemory: fixed experimental proposal

Configuration fixed in source on 2026-11-01 before the first common-holdout evaluation. This dossier records that configuration and its first result. Context-dependent aggregation is established prior work.

The hypothesis is that recurring contexts within one series can identify which forecasters will be useful at the next origin. The proposed rule combines five existing point/quantile forecasters, using only historical prediction errors whose entire horizon is already observed. A query's normalized slope, recent level change, volatility ratio and seasonal correlation determine a kernel over those past contexts. Recency decays with a half-life of six stored origins. The kernel-weighted expert losses shrink 25 percent toward global recency losses, then a temperature-one exponential transformation and a five-percent uniform floor produce convex weights. At most twelve completed origins are used. A bandwidth floor of 0.25 keeps the context kernel defined. These values are fixed, not chosen by the final results.

The experts are SeasonalNaive, SES, Holt, HoltWinters and the finite-history nonseasonal Theta equation. Each produces three Gaussian-approximation quantiles; the combination averages matching quantiles. That operation is not a calibrated mixture distribution and provides no coverage guarantee. The method and its two ablations share exactly the same experts, input history and eligible training origins. EqualMean removes both context and loss adaptation. RecencyMean removes the context kernel and retains loss adaptation.

The proposal is refuted in this experiment if it fails to improve average final-holdout MASE over RecencyMean. Results must also be reported per case, with coverage and interval width, so an apparent aggregate gain cannot hide a failing regime. No threshold is selected after seeing a result. Fifteen selected series with one origin each cannot support population superiority or statistical significance.

The first execution gives mean MASE 1.1921 for ContextMemory, 1.1898 for RecencyMean and 1.3047 for EqualMean. The context component therefore fails its aggregate criterion. These results, both ablations and all case outcomes remain in the released comparison. The method's positive-scale/location equivariance, completed-target eligibility and quantile ordering are checked independently of its empirical ranking.

Related work matters to the interpretation. [FFORMA](https://doi.org/10.1016/j.ijforecast.2019.02.011) trains a feature-to-weight meta-model across reference series. [Arbitrage of forecasting experts](https://doi.org/10.1007/s10994-018-05774-y) learns dynamic expert losses and explicitly discusses recurring changes. The present rule replaces a trained cross-series arbiter with a small, completed-origin within-series kernel and a fixed global shrinkage. That difference defines an experiment, not evidence of global novelty. A stronger follow-up must compare against faithful FFORMA/ADE implementations and multiple origins before making a research-contribution claim.
