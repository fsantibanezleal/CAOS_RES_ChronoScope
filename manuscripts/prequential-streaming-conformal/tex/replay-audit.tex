\subsection{Reconstructing the numerical state at an arrival}
The evidence distinguishes the information used to issue an interval from state written after scoring it. Each row contains the original cutoff, actual target, lower endpoint, point, upper endpoint, normalized score, buffered multiplier, effective levels before and after the update, accumulated error after the update, difference term, buffer size after insertion, hit indicator and historical quantile-loss value. These fields permit a direct audit of a controller transition. They are not interchangeable snapshots: using the after-update level to recreate the same row's forecast would allow its outcome to change its own interval.

For a controlled stream, the score buffer before its first scored arrival is empty. At the $j$th scored arrival, indexed from zero, its size before forecasting is $\min(200,j)$ and its size after insertion is $\min(200,j+1)$. The prior buffer can be reconstructed by taking at most the most recent two hundred normalized scores from earlier rows, in order. The current row's score is excluded. Its saved multiplier should then agree with the default linear-interpolation quantile at one minus the saved before-update level, except for the declared empty-buffer multiplier of one. Raw references do not append controller scores, so their saved controller-buffer count remains zero.

The before-update effective level also has a cross-row constraint. The first value is the target miscoverage; every later value equals the preceding after-update level. The PID-style accumulated error is reconstructed from the target-minus-miss sequence, with a zero initial integral and zero initial difference. These checks distinguish a correct numerical recurrence from an artifact that contains plausible-looking but inconsistent state columns. They also make clipping observable without treating a clipped value as evidence of stability.

Source reconstruction is a separate prerequisite. The stream uses all original ordered observations, whereas the browser display trace can retain only indexed samples from a longer history. The audit matches those samples at their original positions and verifies reserved targets at the export tolerance; it never treats separated display samples as consecutive arrivals. Full-precision source arrays and exact byte bindings identify the calculation. Their preservation addresses the earlier missing per-update evidence, while the unavailable original timing environment and some upstream acquisition revisions remain disclosed limitations. Reconstructing these numerical states is a reproducibility improvement, not a new statistical replication.
