\subsection{Design, comparisons and inferential units}
The historical experiment was not preregistered. Its selected cases, point base and controller settings were inherited from the released implementation. The reconstructed study therefore asks retrospective questions: whether the recorded controllers reduce each stated coverage error on those same streams; how width-sensitive scores change; whether conclusions persist across the fixed coverage and gain grid; and how much the generated mechanisms change at two additional seeds. These questions organize the evidence without pretending that the original settings were chosen through a prospectively documented validation study.

All compared interval rules observe the same target at the same cutoff. They use the same warmup, seasonal lag and nominal coverage within a setting. The raw S+D reference, its ACI-style controller and its PID-style controller share an identical point path. This pairing removes target and point-prediction differences from their interval comparison. Seasonal naive provides another base, not a fourth interval treatment on the S+D point path. The sensitivity grid repeats the interval treatments around each base so that the point-base choice remains visible rather than confounded with the gain multiplier.

The statistical unit for a cross-case summary is one complete stream. There are 5,324 scored cutoffs across the original fifteen cases and four methods per cutoff, producing 21,296 method-cutoff records. These records do not constitute 21,296 independent replications. Arrivals share histories, controller state and overlapping rolling windows; paired methods additionally share each target. Equal-case weighting answers a question about the selected inventory. Equal-arrival weighting would answer a different question and allow longer streams to dominate. Neither weighting scheme establishes representative sampling of an operational population.

The new retrospective extension fixes its resampling settings in a committed analysis plan before computing that extension, while explicitly recording that the original outcomes were already known. It uses ten thousand PCG64 draws with seed 20261105. Each draw samples fifteen complete case identities with replacement and applies the same identities to all methods and both metrics. Point forecasts, targets and within-case trajectories are never resampled separately. The paired difference for a controller $A$ and raw reference $R$ is
\begin{equation}\label{eq:case-paired}
 d_i=L_{i,A}-L_{i,R},\qquad
 \widehat\Delta=\frac1{15}\sum_i d_i,\qquad
 \widehat\Delta^*=\frac1{15}\sum_{j=1}^{15}d_{I_j}.
\end{equation}
The reported interval uses the 2.5 and 97.5 percentiles of the resampled means. Bootstrap resampling originates in empirical-distribution inference~\cite{efron1979}; dependence within a time series requires additional treatment when individual observations are resampled~\cite{kunsch1989}. Here the full-case draw preserves within-stream dependence but does not remove dependence between source cases or create a random sampling design. The endpoints are consequently presented as exploratory case-reweighting sensitivity, not a population coverage guarantee. There is no multiplicity adjustment, no gain selection from these endpoints and no new independent confirmation.
