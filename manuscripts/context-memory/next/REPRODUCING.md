# Rebuilding the external comparison and this document

Use the complete source snapshot distributed with this document. The original
admitted numerical archive records NumPy 2.4.6, SciPy 1.15.3, StatsForecast 2.0.3
and Numba 0.68.1. The Python runtime, historical machine identity and end-to-end
parallel makespan were not retained in that archive. Do not substitute current
hardware information for those missing historical fields.

The full original paths are in `../evidence/external-evaluation.json.gz`; its
compressed and decompressed SHA-256 values are bound by
`data/derived/validated-combinations.json`. The raw M4 Weekly and M3 Monthly TSF
files are identified there and in the archive's `datasets`/`input_sha256` fields.
Supply those exact files in `<source-folder>`; a source-prefix checker refuses
changed sequence identities and actuals. Use an external cache/output folder.

To check the admitted archive against the two exact Monash source files, expand
the gzip stream into an external scratch path and pass that JSON to the checker.

```text
python -c "import gzip, shutil, sys; src=gzip.open(sys.argv[1], 'rb'); dst=open(sys.argv[2], 'wb'); shutil.copyfileobj(src, dst); dst.close(); src.close()" manuscripts/context-memory/evidence/external-evaluation.json.gz <external-archive.json>
python scripts/check_combination_study.py <external-archive.json> --source-root <source-folder>
```

A fresh expert fit is a new execution, distinct from rescoring stored forecasts:

```text
python scripts/run_combination_study.py --source-root <source-folder> --cache <external-cache> --output <external-results.json> --workers 4
python scripts/check_combination_study.py <external-results.json> --source-root <source-folder>
```

Do not overwrite the admitted archive with that run. Its cache fingerprint binds
protocol, source inputs, implementation and package versions. The original
hardware-dependent `seconds` are per-series durations, not an end-to-end speed
benchmark and not additive wall time across parallel workers.
