# Rebuilding the external comparison and this document

Use the complete source snapshot distributed with this document. The original
admitted numerical archive records NumPy 2.4.6, SciPy 1.15.3, StatsForecast 2.0.3
and Numba 0.68.1. The Python runtime, historical machine identity and end-to-end
parallel makespan were not retained in that archive. Do not substitute current
hardware information for those missing historical fields.

The full original paths are in `../evidence/external-evaluation.json.gz`; its
compressed and decompressed SHA-256 values are bound by
`data/derived/validated-combinations.json`. The raw M4 Weekly and M3 Monthly TSF
files are identified there and in the archive's `datasets`/`input_sha256` fields.
Supply those exact files in `<source-folder>`; a source-prefix checker refuses
changed sequence identities and actuals. Use an external cache/output folder.

A fresh expert fit is a new execution, distinct from rescoring stored forecasts:

```text
python scripts/run_combination_study.py --source-root <source-folder> --cache <external-cache> --output <external-results.json> --workers 4
python scripts/check_combination_study.py <external-results.json> --source-root <source-folder>
```

Do not overwrite the admitted archive with that run. Its cache fingerprint binds
protocol, source inputs, implementation and package versions. The original
hardware-dependent `seconds` are per-series durations, not an end-to-end speed
benchmark and not additive wall time across parallel workers.

To reconstruct the paired-series summaries and rendered scientific inputs from
the admitted archive, use the declared numerical environment:

```text
python scripts/summarize_combination_uncertainty.py --output <external-paired.json>
python scripts/plot_combination_uncertainty.py --output manuscripts/context-memory/next/figures
python scripts/build_combination_review_tables.py --check
python scripts/build_working_manuscripts.py --only context-memory --scratch <external-build-folder>
python scripts/check_working_draft_bindings.py
```

Compare the numerical `comparisons` in `<external-paired.json>` to
`../evidence/paired-series-uncertainty.json`; environment/source fields describe
that separate invocation. The plotting script reads the bound retained paired
file. Run `build_combination_review_tables.py` without `--check` to regenerate
its inventory, eight paired comparisons and horizon-aware count input. It
checks the archive digests before computing these tables. The original complete
12-method collection table and result figure are generated by
`scripts/build_combination_report.py`; the working manuscript retains copies
of those generated inputs. The expert diagram is an explicitly illustrative
information-order drawing, not an extra measured outcome.

`build_working_manuscripts.py` invokes the recorder-enabled LaTeX build outside
the source tree and writes a PDF/input identity receipt. `tex/main.tex` lists
the required LaTeX packages. The receipt identifies compiled inputs, without
claiming publication or independent scientific acceptance.
